One note left on the door screen by a smart fridge that has had enough: **"Day 6 of the diet. I watched you hide the cake behind the salad. The salad told me. The salad is also disappointed."** — dry, petty, and specific, 115 characters on a single line.

## Run it

```sh
node main.ts
```

It writes the single line to `/output/entry.txt` (no trailing newline) and prints it to stdout. Deterministic, standard library only, no network.
